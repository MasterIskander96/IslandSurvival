# Island Survival 🏝️🌴

A simple console survival game where the player tries to survive on a mysterious island.

## 📌 About the Project

**Island Survival** is a simple programming project where the player must make decisions to survive on a deserted island.

The player explores the island, collects resources, manages their health and energy, and makes choices that affect their survival.

## 🎮 Features

* 🏝️ Explore a mysterious island
* 🌴 Collect useful resources
* 🍎 Find food and water
* ❤️ Manage health
* ⚡ Manage energy
* 🎲 Random survival events
* 🧭 Make important decisions
* 💀 Game over when the player cannot survive
* 🏆 Try to survive as many days as possible
* 🎯 Interactive console interface

## 🕹️ How to Play

1. Start the program.
2. Choose an action.
3. Explore the island and collect resources.
4. Find food and water to stay alive.
5. Manage your health and energy.
6. Make decisions when random events occur.
7. Try to survive as many days as possible.
8. Keep playing until you escape the island or lose the game.

## 📜 Game Rules

* 🍎 Food restores energy.
* 💧 Water is necessary for survival.
* ❤️ Losing all health ends the game.
* ⚡ Energy decreases when performing actions.
* 🎲 Random events can help or hurt the player.
* 🏝️ The goal is to survive and eventually escape the island.

## 💻 Technologies

* Programming Language: **Python**
* Random event generation
* Console input and output
* Conditional statements
* Loops
* Variables
* Basic programming logic

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project folder:

```bash
cd island-survival
```

Run the program:

```bash
python main.py
```
